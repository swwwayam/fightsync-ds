# FightSync DS

### Data Science × Artificial Intelligence × 3D Fighting

FightSync DS is a browser-based 3D fighting game developed as a Data Science and Artificial Intelligence specialization project.

The project combines an interactive 3D combat environment with custom-built Data Science and Artificial Intelligence techniques to create an adaptive and analytically driven fighting experience.

Rather than treating gameplay and machine learning as separate components, FightSync DS uses combat interactions as data that can be analyzed in real time to drive intelligent decision-making and player behaviour analysis.

---

## 🥊 Overview

FightSync DS explores the practical integration of fundamental Data Science and Artificial Intelligence techniques into an interactive game environment.

The project combines:

- Reinforcement Learning using Q-Learning
- Markov Chain-based move prediction
- Naive Bayes player classification
- Real-time combat analytics
- Browser-based 3D gameplay
- Interactive data visualization using HTML5 Canvas

The objective is to demonstrate how machine learning concepts can be integrated into a real-time interactive application rather than being implemented only as standalone models.

## 🧠 Artificial Intelligence & Data Science

### Reinforcement Learning — Q-Learning

FightSync DS implements a custom Q-Learning approach for AI decision-making.

The AI observes the current combat state and selects actions based on learned state-action values. Through rewards associated with gameplay outcomes, the agent can progressively adapt its behaviour.
